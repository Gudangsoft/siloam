Jangan gunakan Filament untuk admin panel. Gunakan AdminLTE 3 + Laravel Breeze.

**Why:** User ingin admin panel yang lebih familiar dan ringan, bukan Filament yang berat.

**How to apply:** Untuk proyek Laravel dengan admin panel, gunakan kombinasi:
- Frontend: Blade + Tailwind CSS + Alpine.js
- Admin Panel: AdminLTE 3 (jeroennoten/laravel-adminlte) + Laravel Breeze auth
